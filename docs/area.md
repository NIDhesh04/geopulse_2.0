# Map Area Selection

**City**: Chicago, IL
**Bounding Box**:
- South Latitude: 41.8750
- West Longitude: -87.6350
- North Latitude: 41.8900
- East Longitude: -87.6150

**Area Size**: ~2.5 km²

**Reasoning**:
Downtown Chicago (The Loop and surrounding area) features a strict, dense grid-like street network. This is ideal for testing the routing engine as there are numerous genuine alternate routes between any two points. It is also an area prone to traffic congestion, making it a realistic test case for the GeoPulse platform.
